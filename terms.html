Program description

Vision is a self-hosted task-automation and monitoring platform. This SMS program delivers automated, transactional notifications generated by that software: reminders and alarms its user created, and notices that a background job has stopped or failed.

Messages are emitted by the application in response to events. No person composes, types or sends them, and there is no conversational or marketing traffic on this program.

Messages go only to the mobile number registered in the application's own configuration. The software exposes no field for any other destination, so no message can be addressed to a third party.

How consent is given

The user registered his own mobile number in the application's configuration, on software he runs on his own hardware; that registration is the consent. There is no web form, no subscriber list, and no keyword opt-in.

Message frequency

Low and irregular — typically a few messages per week, sent only when a reminder comes due or a monitored job fails. The application enforces a hard limit of 20 messages per day and a minimum of 60 seconds between messages.

Cost

The software charges nothing. Message and data rates may apply from the recipient's mobile carrier.

HELP

Reply HELP for help. Support is John Mosley, sole proprietor, reachable at the email address on the associated Twilio account.

STOP

Reply STOP to stop receiving messages. Opt-outs are handled by Twilio Advanced Opt-Out and take effect immediately. START, YES or UNSTOP re-subscribe. Removing the number from the application's configuration also stops all messages.

Carrier disclaimer

Carriers are not liable for delayed or undelivered messages. Delivery depends on the mobile carrier and is not guaranteed; this software treats SMS as best-effort and keeps every notification visible in its own interface as well, so that a dropped message loses no information.
